mini-swe-mcp {VERSION}
Usage: mini-swe-mcp [--stdio | [--json] [--admin] <action> [args...]]
\nActions:
  {DISPATCH_USAGE}
           Start a worker on its own branch; always detaches.
  watch [<worker_id>...] [--group <g>] [--all] [--follow] [--json] [--timeout <secs>]
           Block until the next worker event (replaying missed ones), print it and exit;
           run it in the background and the host CLI wakes you when it ends.
  status <worker_id> | status --line
           Final status/diff, or a one-line pool summary for statusLine.
  collect <worker_id> [--full] [--file <path>]
           Final message with a per-file diff stat; --full adds the whole diff,
           --file narrows it to one path (repeatable).
  review <worker_id> [--diff code|all|none]
           One compact view of a finished worker: task, verification, the code
           diff, per-file stat, tests summarised, and whether it still merges.
  approve <worker_id> [\"note\"]
           Record your verdict on a completed worker (owner-only).
  unapprove <worker_id>
           Withdraw that approval.
  logs <worker_id>
           Recent commands and their output.
  steer <worker_id> <message> [--max-turns <n>]
           Correct a completed worker or continue a stopped one.
  consolidate {CONSOLIDATE_USAGE}
           Integrate one group's round: merge the finished branches, run the full gate
           once, route each failure to its owner, review every diff, and report.
  list [--all]
           Workers you own; --all (with --admin) lists every agent's.
  kill <worker_id>
           Terminate a worker.
  discard <worker_id>
           Drop a stopped worker for good: branch, row, history, steer files and
           worktree leftovers, with no merge. A running worker is refused; kill it
           first.
  merge <worker_id> [--no-delete]
           Merge a finished worker's branch into its base branch: trial merge,
           verify gate on the merge result, then merge --no-ff and clean up.
  merge --approved [--group <group>]
           Land every approved worker of a group with ONE gate on the combined
           result: a conflicting worker is skipped, the rest merge with --no-ff.
  archive [--group <group>] [--last <n>]
           Final reports of already-retired workers (merge, discard, retention):
           done/files/tests/risks, the task, the gate verdict and why it left.
  reap
           Evict expired terminal worker records.
  prune
           Clean stale worktrees and caches.
  manifest
           Print the models catalog.
  monitor [--once]
           Full-screen view of the pool.
  supervisor [--once]
           Health view of workers and the hub.
  daemon
           Run the shared hub in the foreground.
  whoami
           Print this session's agent identity and how it was derived.
  help <topic>
           Long-form guidance on one concern (see Topics below).
\nTopics:
  mini-swe-mcp help <topic>   {TOPICS}
